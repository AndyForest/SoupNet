# PR review helpers: research

Research for [../pr-review-helpers.md](../pr-review-helpers.md), done 2026-09-27 by five parallel sub-agents, each making its own Soup.net searches and feedback (listed in each report's "Soup.net use" section). Every fact is a verbatim quote with a link. Several reports read pages through a summarizing fetch tool and mark those quotes; re-open the link before reusing a quote in public copy.
